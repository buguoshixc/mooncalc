# MoonCalc 语义规范（v1）

本文档记录引擎**已实现**的语义与显式契约。凡与 Excel 可能有出入的条目集中在[语料裁定结果](#语料裁定结果m5excel-2024-已裁决)；实现位置以 `src/` 为准；本文随实现更新。引擎为 **MoonBit**（`src/**/*.mbt`）；`corpus/excel/generate_corpus.bas` 只是 Excel 侧答案键生成器。

## 值模型（src/value）

- `Value = Num(Double) | Text(String) | Bool | Err(XlError) | Blank | Range`。
- **Blank 与 Num(0) 严格区分**：空白格是 `Blank`，不是 0；参与运算/比较时按下方规则转换。
- **公式结果永不为真空白**：输出边界把 Blank 归一为 `Num(0)`（Excel 中 `=A1` 引用空白格得 0，公式格的 ISBLANK 恒为 FALSE）；`""` 是空文本不是空白。Blank 只作为网格输入状态存在。
- `Range` 行主序保留形状（rows×cols）。**1×1 区域可标量化**；>1 格区域进入**标量上下文**（顶层输出）：单列区域取第 1 行（与 Excel 把公式放在 ZZ1 时的隐式交集一致，`=INDEX(A1:C3,0,1)` → 1），行区域/二维区域 → `#VALUE!`（不做动态数组溢出）。区域作为函数参数时保持 `Range`。
- 7 种错误值：`#DIV/0! #N/A #NAME? #NULL! #NUM! #REF! #VALUE!`。
- 地址上限 XFD（16384 列）/ 1048576 行；`$` 绝对标记解析保真（v1 无复制填充场景）。
- **解析失败走独立通道**：`eval_formula` 返回 `Result[_, ParseError]`；网格重算把失败格记入 `parse_errors` 并使该格值为 `#VALUE!`，不混入正常结果。

## 解析器与优先级（src/syntax）

Excel 优先级（高→低）：

| 级 | 运算符 | 备注 |
|---|---|---|
| 80 | `:` 区域 | 仅 引用:引用；B2:A1 归一化为 A1:B2 |
| 70 | `%` 后缀 | `50%` = 0.5 |
| 60 | 一元 `-` / `+` | **`-2^2 = 4`**（负号先于乘方）；**一元 `+` 是恒等运算**（`+"3"` = 文本 `"3"`、`+TRUE` = TRUE，不强制转换；只有一元 `-` 与 `%` 走数值转换） |
| 50 | `^` | **左结合：`2^3^2 = 64`** |
| 40 | `* /` | |
| 30 | `+ -` | |
| 20 | `&` | 文本连接 |
| 10 | `= <> < <= > >=` | |

- 字面量：数字/科学计数、字符串（`""` 转义）、TRUE/FALSE（大小写不敏感）、7 种错误字面量。
- **数字字面量按 Excel 录入精度存储**：最多 15 位有效十进制数字，超出部分直接置零（不四舍五入），如 `123456789012345678` 存为 `123456789012345000`。
- 形如引用但后随 `(` 的记号按函数名处理（如 `LOG10(` 不是单元格）。
- 前导 `=` 可有可无。
- **不支持（解析错误）**：整列/整行（A:A）、交集（空格）、联合（逗号在区域层）、R1C1、定义名称、数组字面量 `{}`、跨表引用 `Sheet1!A1`。

### 公式限制（复刻 Excel，超限返回 ParseError）

| 限制 | 值 | 说明 |
|---|---|---|
| 公式长度 | ≤ 8192 | UTF-16 码元计数（与 Excel 公式栏一致；非 BMP 字符计 2） |
| 嵌套深度 | ≤ 64 | 括号、一元 `+`/`-`、函数调用共用同一深度计数 |
| 单元格地址 | 行 ≤ 1048576、列 ≤ 16384 | 越界地址按解析错误处理（`parse_addr` 返回 `None`） |

这两条限制同时是**不崩溃保证**：任何输入（含恶意构造的超长/超深公式）都只会得到
`ParseError` 或错误值，不会栈溢出。左结合二元链与一元链（含不计入嵌套深度的后缀
`%` 链）在求值期均按迭代折叠（`eval_binary` / `eval_expr` 的 Unary 分支收集算符脊
后自内向外折叠），因此 8192 字符内的长链（约 4000 项）在 native 与 wasm-gc
上均安全；求值顺序与「最左错误优先」传播语义与递归版完全一致。回归与确定性 fuzz
（xorshift32，随机记号汤 + 种子公式变异）见 `src/syntax/limits_test.mbt`、
`src/engine/robustness_test.mbt`。

## 强制转换（src/engine/coerce.mbt，唯一入口）

**locale 不变式**：小数点恒为 `.`；接受**严格千分位分组**（`"1,000"`）与 **ISO 日期文本**（`YYYY-MM-DD` / `YYYY/M/D`，可带 ` HH:MM[:SS]`）；其余 locale 形式（货币符号、US 日期顺序如 `"11/14/2026"`、locale 日期格式）一律 `#VALUE!`（不猜 locale）。

### to_number（算术运算、数值参数）

| 输入 | 结果 |
|---|---|
| Num | 原值 |
| Blank | 0 |
| Bool | TRUE→1，FALSE→0 |
| Text | 裁剪空白后按 Excel 文本→数字解析：可选符号；整数部分可带严格千分位（首组 1–3 位、其后每组恰好 3 位）；可选小数；可选科学计数；可选 `%`；或 ISO 日期/时间文本（转 Excel 序列日）。**解析结果再按 15 位有效数字录入精度截断**。失败 → `#VALUE!` |
| Err | 原样传播 |
| Range | 1×1 递归；否则 `#VALUE!` |

### to_text（`&`、文本参数）

| 输入 | 结果 |
|---|---|
| Num | **Excel General 隐式转换**：先四舍五入到 15 位有效数字；十进制指数在 −18..19 内用定点（整数补零、去尾零），超出用科学计数（尾数去尾零、指数 `E±n` 不补零）。例：`1E19&""`→`"10000000000000000000"`、`1E20&""`→`"1E+20"`、`SQRT(2)&""`→`"1.4142135623731"`、`1E-19&""`→`"1E-19"`。非有限值 → `#NUM!` |
| Text | 原值 |
| Bool | `"TRUE"` / `"FALSE"` |
| Blank | `""` |
| Err | 传播 |
| Range | 1×1 递归；否则 `#VALUE!` |

### to_bool（逻辑参数）

| 输入 | 结果 |
|---|---|
| Bool | 原值 |
| Num | ≠0 → TRUE |
| Blank | FALSE |
| Text | 仅 `"TRUE"`/`"FALSE"`（大小写不敏感）；其余 `#VALUE!` |
| Err | 传播 |
| Range | 1×1 递归；否则 `#VALUE!` |

## 比较排序（`=` `<` 等，**不强制转换**）

- 跨类型全序：**数字 < 文本 < 布尔**，故 `"1" = 1` → FALSE、`1 < "a"` → TRUE。
- 文本比较**大小写不敏感**、逐码点字典序（MoonBit 原生 String 比较是长度优先，已用自定义 lex_compare 替换）；大小写折叠用 Unicode 简单小写映射（BMP 查表），非 BMP 原样。
- Blank 与对方同化：对数字视为 0、对文本视为 `""`、对布尔视为 FALSE；Blank=Blank → TRUE。
- 错误值参与比较 → 传播（左先）。

## 引用 vs 字面量双通道

通道划分以**引用/字面量**为界，不是以单格/区域为界：单格引用 `A1` 同样走引用通道（实现上引用统一包成 1×1 Range，强制转换函数自动解包）。

- **字面量参数**走强制转换：`SUM("3",4) = 7`、`SUM(TRUE,1) = 2`。
- **引用参数**（含单格引用）：SUM/AVERAGE/MIN/MAX/MEDIAN/SUMPRODUCT 等忽略文本与布尔（不转换、不报错），故 `SUM(A1,4)`（A1 为文本）= 4、`AVERAGE(A1)`（A1 为文本）= `#DIV/0!`；**COUNT 只数数字**；**COUNTA 数一切非空**（含公式产生的 `""`）。
- **AND/OR 的引用参数**：数字格按 ≠0 参与、布尔格参与、**文本与空白忽略**；**字面量参数**：数字/布尔参与，文本 `TRUE`/`FALSE`（大小写不敏感）参与、其余文本忽略；**全部参数都没有逻辑值 → `#VALUE!`**（`AND(A1,A2)` 两格均为文本/空白时即如此）。
- 引用内的错误值传播（见下）；**例外**：COUNT 忽略错误参数（含字面量，`COUNT(#N/A) = 0`）、COUNTA 把错误参数计为非空（`COUNTA(#N/A) = 1`）；COUNTIF/SUMIF 的条件区域内错误格只是不匹配、不传播，criteria 参数为错误才传播；SUMIF 求和区域的错误格在被选中求和时传播。SUMPRODUCT 的直接错误参数传播。

## 错误传播与求值顺序

- 二元运算/急切函数：**从左到右最先出现的错误胜出**（`1/0 + #N/A` → `#DIV/0!`）。
- **惰性**：IF（只求值被选分支）、IFERROR（第一参数无错则不求值第二参数）。`IF(TRUE,1,1/0) = 1`。
- **急切**：AND/OR 及其余全部函数。`AND(TRUE,1/0)` → `#DIV/0!`。
- 未知函数 → `#NAME?`；参数个数不符 → `#VALUE!`（显式契约；Excel 实际在录入时拒绝，语料无法覆盖此差异）。

## 网格重算与循环引用（src/engine/eval.mbt）

- `eval_formula`（单公式）/ `eval_at`（单格）/ `recalc`（全网格）共享同一 DFS：引用递归 + cache 记忆化 + on_stack 环检测。
- **循环引用复刻 Excel 默认（迭代计算关闭）：环上每个单元格 = 0**，结果元数据 `circular: true`。
- 只标记 DFS 路径中的**环后缀**：`=D1+1` 自环的 D1 标 circular；依赖环的 `D2==D1+5` 得 5 且 circular=false（与 Excel 一致：依赖格拿到 0 继续算）。
- 无系统时钟、无随机：同一输入必然同一输出（时钟经注入，见下）。

## 函数边界语义（50 函数）

### 逻辑（7）
IF / IFERROR / IFS / SWITCH 惰性；AND/OR 急切、引用参数见双通道（数字/布尔参与、文本空白忽略，无逻辑值 → `#VALUE!`）；NOT 走 to_bool。

- **IFS**：条件/值成对，逐条件 `to_bool`（条件错误传播），首个 TRUE 返回对应值且不继续求值；无匹配 → `#N/A`；奇数参数 → `#VALUE!`。注意：真实 Excel 拒绝录入奇数参数的 IFS（VBA 1004），无法产生答案键；该行为属于显式子集外（spec 标 `subset-out`，不进入基准分母）。
- **SWITCH**：表达式只求值一次；候选值逐个求值并用 `=` 语义比较（`cell_eq`，大小写不敏感、无通配）；**表达式或任一已求值候选为错误值时立即传播该错误**（语料 `logic-switch-0008/0009`），命中后只求值命中结果；末尾落单参数是默认值（未命中才求值）；无匹配且无默认 → `#N/A`。

### 数学（11）
- **ROUND/ROUNDUP/ROUNDDOWN：half-away-from-zero，十进制字符串修正**——`ROUND(2.675,2) = 2.68`（朴素 double 会得 2.67）；负位数作用于整数位。
- **MOD 符号随除数**：`MOD(-3,2) = 1`、`MOD(3,-2) = -1`；除数 0 → `#DIV/0!`。
- **POWER/`^`**：`0^0 = #NUM!`；`0^负数` → `#DIV/0!`；负底数仅接受整数次幂（`(-8)^3 = -512`）或**奇数倒数**次幂（`(-8)^(1/3) = -2`、`(-32)^0.2 = -2`），其余（`(-8)^(2/3)`、`(-4)^0.5`）→ `#NUM!`。
- INT 向下取整（`INT(-2.5) = -3`）；ABS 平凡。
- SUM/SUMIF/SUMPRODUCT：SUMIF criteria 支持比较符前缀（`">2"`、`"<>x"`）与通配符 `* ? ~`；空条件 `""`/`"="` 匹配空白格与空文本格，`"<>"` 匹配一切非空白格（含公式产生的空文本，语料 `math-sumif-0116/0117/0118`）；条件为错误值时与同值错误格匹配（无匹配则 0，匹配到和区域中的错误则传播，语料 `math-sumif-0125`–`0128`、`gen-sumif-0002`）；SUMPRODUCT 形状不齐 → `#VALUE!`，区域内非数值按 0。
- 溢出/非有限结果 → `#NUM!`。

### 统计（7）
AVERAGE 无数值 → `#DIV/0!`；MIN/MAX 无数值 → 0；COUNT/COUNTA 见双通道；COUNTIF 同 SUMIF criteria（含空条件/错误条件规则，语料 `stat-countif-0118/0119/0121/0125`）；MEDIAN 偶数个取中点均值。

### 文本（13）
- **LEFT/RIGHT 按 Unicode 码点计**（`LEFT("😀abc",1)` = `"😀"`）；**MID 按 UTF-16 码元计**（`MID("a😀b",2,1)` 为孤立代理项，`LEN(...)=1`）；n<0 / start<1 → `#VALUE!`；越界裁剪不报错。
- **LEN 数 UTF-16 码元**：`LEN("😀") = 2`、`LEN("a😀b") = 4`。
- **UPPER/LOWER 用 Unicode 简单大小写映射**（逐字符、无展开）：`LOWER("CAFÉ") = "café"`、`LOWER("İ") = "i"`、`UPPER("straße") = "STRAßE"`（ß 保持，与 Excel 一致）；实现为 BMP 区间/映射表，非 BMP 原样。
- **TRIM 仅压缩 ASCII 空格**（去两端、内部连续压成一个；不动 tab/全角空格）。
- **FIND 大小写敏感、无通配符**；位置按 UTF-16 码元计（`FIND("b","a😀b") = 4`）；找不到 → `#VALUE!`；空 needle 返回 start。
- SUBSTITUTE 第 4 参指定第几次出现（<1 → `#VALUE!`）；空 old 原样返回。
- CONCAT 区域逐格拼接；VALUE 走 to_number 的文本解析，错误参数原样传播（`VALUE(#N/A)` → `#N/A`）。
- **TEXTJOIN**：`TEXTJOIN(delimiter, ignore_empty, text1, …)`，区域按行主序逐格 `to_text` 拼接；`ignore_empty=TRUE` 跳过空白格与空文本（含公式产生的 `""`），FALSE 时空白格贡献空串；错误（分隔符/ignore_empty/区域格）传播；结果长度 >32767 个 UTF-16 码元 → **`#CALC!`**（Excel 2024 动态数组计算错误，语料 `text-textjoin-0021`）；全部被跳过 → `""`。
- TEXT 见专节。

### 查找（5）
- **XLOOKUP**：`XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])`。lookup_array/return_array 必须是**行向量或列向量**且长度相同（否则 `#VALUE!`）；match_mode：0 精确（默认）、-1 精确或次小、1 精确或次大、2 通配符（仅文本，大小写不敏感，`* ? ~`）；search_mode：1 从前往后（默认）、-1 从后往前、2 升序二分、-2 降序二分。命中返回对应 return 格，空白结果归一为 0；未命中时才求值 `if_not_found`，缺省 → `#N/A`。**二分模式按标准 lower_bound 实现**（排序假设；无序输入可能落到未命中，语料 `lookup-xlookup-0027`–`0048`；降序重复键取降序小端最近的一次，符合 2024 实测）；**二分 + 通配符不组合（`#VALUE!`）**；match_mode/search_mode 必须为整数，小数 → `#VALUE!`（语料 `lookup-xlookup-0036`）。可选参数中间不能省略（解析器不支持空实参），需要 search_mode 时须显式给出 if_not_found 占位值。
- VLOOKUP/HLOOKUP：第 4 参 FALSE/0 精确（找不到 `#N/A`）；TRUE/省略近似（首列/行升序假设，取 ≤lookup 的最后一项，小于最小值 → `#N/A`）。col/row_index <1 → `#VALUE!`，超出表宽 → `#REF!`。
- MATCH：0 精确（支持通配符）、1 升序近似、-1 降序近似；找不到 `#N/A`。精确匹配空文本时空白格不算命中（`MATCH("",{"abc",blank,""},0)=3`，语料 `lookup-match-0107/0111/0112`）；XLOOKUP 空查找同规则。
- INDEX：row/col = 0 返回整列/整行（Range 值）；顶层标量上下文下**单列结果取第 1 行**（`=INDEX(A1:C3,0,1)` → 1）、行/二维结果 → `#VALUE!`（见值模型）；越界 → `#REF!`。

### 日期（7）
- **EOMONTH**：`EOMONTH(start_date, months)` 返回 `start_date` 之后 `months` 个月那个月的最后一天序列日。两个参数都走 `date_arg`（trunc；`|d|>1e7` → `#NUM!`）；实现为 `serial_to_ymd(start)` 后按月算术得到目标年/月，再取**公历月末**（1900 年不是闰年）并映射回序列日。因此 `EOMONTH(60,0)=59`（不是幻影日 60）、`EOMONTH(1,-1)=#NUM!`、`EOMONTH(0,0)=31`、`EOMONTH(DATE(9999,12,1),0)=2958465`、`EOMONTH(2958465,1)=#NUM!`（语料 `date-eomonth-0016`–`0021`）。

- **1900 日期系统 + Lotus bug**：serial 60 = 幻影 1900-02-29；1..59 用 epoch 1899-12-31，≥61 用 1899-12-30；serial 0 → DAY=0。
- **DATE 算法（按 Excel 实测）**：年参数 0..1899 先 +1900；再按月溢出归一化（`DATE(2026,13,1)` → 2027-01-01；归一化落到 1899 → `#NUM!`，故 `DATE(1900,0,1)` = `#NUM!`）；序列 = 该月 1 日的 Excel 序列（1900 年 1–2 月按幻影日之前的历法，其余按含幻影日的历法）+ (d−1)。因此 **`DATE(1900,2,29)=60`、`DATE(1900,3,0)=60`、`DATE(1900,2,30)=61`、`DATE(1900,1,0)=0`、`DATE(1900,3,-1)=59`**。年 >9999 或参数使序列越界（<0 或 >2958465）→ `#NUM!`。
- **文本日期**：`YEAR/MONTH/DAY` 等数值参数走 to_number，因此接受 ISO 日期文本（`YEAR("2026-11-14")=2026`），日期文本必须能按幻影历往返（`"1900-02-29"` 接受，`"2026-02-30"` → `#VALUE!`）。
- 负 serial / ≥2958466 → `#NUM!`。
- **时钟注入契约**：`EvalOptions { now : Double? }`（序列日含小数）。TODAY=INT(now)、NOW=now；**未注入 → `#NUM!`**（核心不读系统时钟，CLI `--now` 在壳层转换 ISO/serial）。

## TEXT 子集（src/engine/text_format.mbt，M6 加深并由 Excel 2024 裁定）

- 数字段：`0 # ? . , %`、引号字面量、`\` 转义；最多 3 分段 `正;负;零`。
- **科学计数（M6 解锁）**：`E+`/`E-` 标记（`0.00E+00`、`0.00E-00`）。`E+` 正指数显式带 `+`；`E-` 仅负指数带 `-`。指数占位符个数是最小宽度（实际指数更宽时不截断）。尾数为「1 位整数 + 格式指定的小数位」；舍入进位会调整指数（`TEXT(9.99,"0.0E+00")="1.0E+01"`）。裸 `E`（无符号）与指数段再次出现 `.`/`,` 等 → `#VALUE!`。
- **累计时长（M6 解锁）**：`[h] [hh] [m] [mm] [s] [ss]` 按序列日累计渲染（天×24 小时等，**不** mod 24/60）；双字母补零到 2 位。`[h]:mm:ss` 组合按累计小时 + 当天时分秒渲染。
  - 负值时：**单段且仅含一个累计 token**（如 `TEXT(-0.5,"[h]")="-12"`）→ 带负号渲染；单段组合累计格式（`[h]:mm`、`[m]:ss`）→ `#VALUE!`；多段时按符号选段、对累计格式渲染绝对值（`TEXT(-2,"[h];[m]")="2880"`）。均为 Excel 2024 实测（语料 `text-text-0122/0123/0153`）。
- **条件分段（M6 解锁）**：分段前缀 `[op num]`（`>= <= <> > < =`，可省略 `=`）。选择规则（Excel 2024 实测，语料 `text-text-0125`–`0161`）：
  1. 无任何条件段：正数取第 1 段、负数取第 2 段（缺则第 1 段并自动加负号）、零取第 3 段（缺则第 1 段）。
  2. 有条件段：按顺序取**首个命中**的条件段；无条件的段仅作为「所有条件都不命中」时的默认段。
  3. 全部段都是条件段且都不命中：仅一段时回退到 Excel 的 General 数字文本（如 `TEXT(50,"[>100]0.00")="50"`），多段时 `#VALUE!`（`text-text-0126/0145`–`0161`）。General 回退对负值的自动负号规则：条件可能匹配负数（阈值为负，或 `[>0]/[>=0]/[<0]/[<=0]` 符号边界）时省略负号，否则保留（`TEXT(-50,"[>-10]0.0")="50"` vs `TEXT(-50,"[>1]0.0")="-50"`）。`|x| >= 1e11` 的 General 科学计数表征属子集外，响亮 `#VALUE!`。
  4. **符号标记段**（`>`/`>=`/`<`/`<=` 与 0 比较）渲染绝对值并抑制自动负号；其他条件段命中时负号照常保留（`TEXT(-50,"[<100]0.0")="-50.0"`）。默认段/无条件下自动负号按常规规则（`TEXT(-50,"[>100]0;0.0")="-50.0"`）。
- **日期时间子集**（格式串含 y/m/d/h/s 字母或 `[h]/[m]/[s]` 即按日期时间渲染）：`yyyy yy m mm mmm mmmm d dd ddd dddd h hh m mm（时/分语境）s ss AM/PM A/P`，支持 `: / - . 空格` 字面量与引号/转义；月份与星期名为英文（与 zh-CN Excel 一致）；m/mm 在已出现 h/s（含累计时长 token）之后的时区段按分钟解释，或在分隔符后紧跟 s 时按分钟解释。例：`TEXT(5,"yyyy")="1900"`、`TEXT(60,"yyyy-mm-dd")="1900-02-29"`、`TEXT(0.5,"[m]:ss")="720:00"`。
  - **日期格式也支持 `;` 分段与条件前缀**（M6 裁定，语料 `text-text-0139/0141/0158/0160`）：正数取第 1 段，负数取第 2 段但**负序列日的日期渲染为 `#VALUE!`**（负累计时长除外），零取第 3 段；条件前缀与符号标记规则同上；混用数字段时按选中段语义分派（`TEXT(1.5,"[h];0")="36"`、`TEXT(-5,"0;yyyy")=#VALUE!`）。
- 文本输入原样返回；TRUE/FALSE 转大写词。
- **`TEXT(...,"General")` → `#VALUE!`**（zh-CN Excel 实测行为；与普通数字→文本的 General 隐式转换不同）。
- **子集外一律 `#VALUE!`（响亮失败）**：颜色 `[Red]`、locale `[$-...]`、分数 `?/?`、locale 星期名 `aaa/aaaa`、General 回退且 `|x| >= 1e11`。

## 不支持特性清单（显式排除）

动态数组/溢出、隐式交集 `@`（顶层单列 Range 的取首行行为只模拟了宏取 ZZ1 的场景）、整列整行引用、跨表/跨簿引用、定义名称、R1C1、数组字面量、函数调用中的空实参（如 XLOOKUP 省略中间可选参数）、迭代计算（循环=0 固定）、1904 日期系统、locale 相关解析与格式（货币、非 ISO 日期顺序、locale 文本函数）、非 BMP 大小写映射、locale 星期名/月份名、TEXT 颜色/locale 前缀/分数段、`TEXT` General 回退且 `|x|>=1e11`、XLOOKUP 二分+通配符组合、IFS 奇数参数（Excel 拒绝录入，spec 标 `subset-out`）。

## 数值对照策略（bench）

- **match**：数值精确相等（Double 位相等），文本/布尔/错误按值相等。
- **excel-precision**（通过，单列披露）：数值相对差 ≤ 1e-14。来源是 Excel/VBA 只能以 **15 位有效数字**序列化答案（`CStr`），因此 15 位表征差不算行为差异（本版 1 条：`SQRT`）。
- **clock-tolerance**（通过，单列披露）：用例带 `clock` 标签且数值**绝对差 ≤ `--clock-tol`（默认 1e-6 天 ≈0.086 s）**。`now` 由生成器在同一重算中经 `=NOW()` 辅助格捕获（见 `corpus/cases/PROVENANCE.md`），派生运算的尾差在此容差内（本版 4 条）。
- **numeric-tolerance**（失败）：相对差介于 1e-14 与 `--tol`（默认 1e-9）之间，单独归因。
- **value-mismatch / type-mismatch / parse-error**：失败并逐条列出 expected/actual。

## 语料裁定结果（M5，Excel 2024 已裁决）

以下条目由 `corpus/spec/` 埋点、真实 Excel 2024（16.0.20527.20196, zh-CN）回答；引擎已按裁定修正，当前语料（1,001 条）全部通过。

1. **COUNT/COUNTA 的错误参数**：COUNT 忽略一切错误参数（`COUNT(#N/A)=0`、`COUNT(1/0)=0`），COUNTA 把错误参数计为非空（`COUNTA(#N/A)=1`）——直接错误参数也如此（原实现错误地传播）。
2. **AND/OR 的引用通道**：数字格按 ≠0 参与（`AND(1,1)=TRUE`、`AND(1,0)=FALSE`）；文本格忽略；全无逻辑值 → `#VALUE!`；字面文本仅 `TRUE/FALSE` 参与，其余忽略（`AND("0",TRUE)=TRUE`）。
3. **一元 `+` 是恒等运算**：`+"3"="3"`、`+TRUE=TRUE`、`+"abc"="abc"`（原实现错误地强制转数值）。
4. **POWER(0,0) = `#NUM!`**（`0^0` 同）；负底数**奇数倒数**次幂可得负根（`(-8)^(1/3)=-2`），其余非整数次幂 `#NUM!`。
5. **INDEX 的 0 行/列**：`INDEX(range,0,n)` 返回整列 Range（顶层取首行 = 1）；`INDEX(range,0,0)`/行结果在顶层 → `#VALUE!`（宏把公式放在 ZZ1，等价于隐式交集到 ZZ1 列）；`SUM(INDEX(range,0,0))=SUM(整表)`。
6. **LEN/LEFT/RIGHT/MID/FIND 的 UTF-16 语义**：LEN 数码元（`LEN("😀")=2`）；LEFT/RIGHT 数码点；MID 数码元（可产出孤立代理项）；FIND 返回码元位置（`FIND("b","a😀b")=4`）。
7. **VALUE 的错误传播与文本解析**：`VALUE(#N/A)` → `#N/A`（不吞成 `#VALUE!`）；接受严格千分位（`VALUE("1,000")=1000`）与 ISO 日期文本（`VALUE("2026-11-14")=46340`），拒绝 `"1,00"`、`"11/14/2026"`。
8. **数字→文本（General 隐式转换）**：15 位有效数字四舍五入；指数 −18..19 定点、其余科学计数；`123456789012345678&"" = "123456789012345000"`（字面量录入精度截断 + 表征）。数字字面量按 15 位截断入引擎。
9. **TEXT**：zh-CN 下 `TEXT(123,"General")=#VALUE!`；日期时间码可用（`TEXT(5,"yyyy")="1900"`、`TEXT(60,"yyyy-mm-dd")="1900-02-29"`）；其余子集外仍 `#VALUE!`。
10. **DATE 的 Lotus 幻影日与年偏移**：`DATE(1900,2,29)=60`、`DATE(1900,3,0)=60`、`DATE(1900,2,30)=61`、`DATE(1900,0,1)=#NUM!`、`DATE(1899,12,31)=693962`（年 1899→3799）。
11. **文本日期参与数值转换**：`YEAR("2026-11-14")=2026`（ISO 形式），US 顺序 `"11/14/2026"` → `#VALUE!`。
12. **时钟基准**：`now` 必须与答案格同一次重算的 `NOW()` 值一致；生成器改用 `=NOW()` 辅助格捕获后，所有时钟用例在容差内一致。
13. **浮点尾差**：15 位表征差单列 `excel-precision` 桶并通过；时钟派生尾差用 `clock_tol`（绝对天数）单列 `clock-tolerance` 桶并通过。无未归因失败。

## M6 语料裁定结果（Excel 2024，1,001/1,001 通过）

以下探针由 `corpus/spec/*.tsv` 埋点、真实 Excel 2024（16.0.20527.20196, zh-CN）回答；引擎已按裁定修正，`corpus/reports/real.json` 通过率 100%，容差桶 996 match + 4 clock-tolerance + 1 excel-precision。

1. **TEXTJOIN 超长**：`=LEN(TEXTJOIN("",TRUE,A1:B1))`（40,000 字符）→ **`#CALC!`**（不是 `#VALUE!`）；生成器错误码映射与引擎 `XlError` 均已扩展（`text-textjoin-0021`）。

4. **criteria 空条件/错误条件**：`""`/`"="` 匹配空白格与空文本格；`"<>"` 匹配非空白格（含公式空文本）；错误条件与同值错误格匹配，SUMIF 会传播匹配到的和区域错误（`math-sumif-0116`–`0118`、`0125`–`0128`、`stat-countif-0118/0119/0121/0125`、`gen-sumif-0002`）。

7. **SWITCH 错误传播**：表达式或已求值候选为错误值时立即传播；命中结果/默认值仍惰性（`logic-switch-0008/0009`）。

## 迭代计算（opt-in）

`recalc_iterative` / `eval_formula_iterative` 对齐 Excel「启用迭代计算」：环上格从 0
起按网格插入序就地迭代（Gauss-Seidel），一轮内最大绝对变化 < `max_change`（默认
0.001）或达 `max_iterations`（默认 100，Excel 上限 32767）即停；环上格 `circular: true`
但值为迭代结果（不再是 0）。非环格与 `recalc` 一致。**默认 `recalc` 路径不变**（迭代
关闭是 Excel 默认，环上为 0）。`now` 注入一次、跨轮不变（确定性）。

语料：`corpus/spec/iter.tsv`（spec 可选第 6 列 `iter=N:C`；生成器对该用例临时设置
`Application.Iteration/MaxIterations/MaxChange` 并抑制循环引用弹窗，读取答案后立即
还原；record 追加可选 `iter` 字段，bench 走 `eval_formula_iterative`）。围栏（100 轮
还是 101）、迭代序（网格序 vs Excel 依赖序）与收敛细节以真实 Excel 答案键裁定；
