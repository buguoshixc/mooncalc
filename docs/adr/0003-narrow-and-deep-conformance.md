# 窄而深：限定函数子集，逐个严格对照 Excel

- 状态：**Superseded by ADR 0009**（2026-11-21；原决策保留作历史，不再作为最终验收终点）

引擎只支持约 40–60 个核心 Excel 函数，但每个都严格复刻 Excel 语义（弱类型强制转换、错误值传播、边界情形），并以真实 Excel 生成的答案键语料逐条对照。放弃「支持 150+ 函数」的宽而浅路线。

## 备选方案

- 宽而浅（150+ 函数覆盖常见路径）：功能清单好看，但边界差异多、对照通过率偏低且难以归因，容易被判定为玩具实现。
- 分层（核心严格 + 扩展 experimental）：功能面更大，但会稀释对照通过率这一核心指标的说服力。

## 后果

函数子集是公开契约的一部分，必须在文档中明确列出；子集外的函数行为需显式定义而非猜测。项目对外的核心叙事是「N 条真实 Excel 用例，通过率 X%，剩余差异逐条归因」，而不是函数数量。
