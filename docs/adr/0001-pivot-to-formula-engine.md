# 放弃 MoonPack，转向电子表格公式引擎

MoonPack（MoonBit 仓库上下文打包 + 检索评测）的功能已被 `Delthin/moon_repomix` v0.7.0 覆盖：该包已具备 MoonBit `.mbt`/`.mbti` 符号与依赖索引、任务预算规划、精确 `o200k_base` 计量、按需补读，以及 CLI/SDK/MCP/WebUI 四种交付形态；改造为「上下文审计」的备选路线也已被 `lllg123/mooncontext` 占据。我们决定放弃该方向，转做电子表格公式引擎。

## 备选方案

- 保留 MoonPack 只做评测模块：评测类无获奖先例，且无 LLM API 时只能测代理指标，无法证明端到端价值。
- 走社区维护路径给现有项目贡献：规则允许，但对个人作品集的展示价值低于原创项目。

## 后果

本机 mooncakes 索引实测 3670 个模块、254 个 agent/LLM 相关模块，探测的约 50 个候选域全部被占。因此选题不再以「无人做过」为标准，而以「有权威参照可机械验证、边界清晰、可在一个月内交付」为标准。公式引擎是本次调研中唯一有完整证据的库级空白。
