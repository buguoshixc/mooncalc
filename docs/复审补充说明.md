# 复审补充说明（MoonCalc，2026-11-21）

> 以下内容可直接粘贴到报名表/复审说明栏。链接在仓库 push 后生效；数字均为本仓库实跑结果。

## 1. 已明确目标标准及版本

本项目的目标标准不再是自定义公式子集，而是：

**Microsoft Excel 2024 / 2610（Build 16.0.20527.20196，zh-CN）的公式语言与计算语义。**

范围覆盖公式语法、引用语义（相对/绝对、跨表、整列整行、定义名称、3D、外部链接）、运算符（含区域交集空格、并集逗号、`@`、`#`）、隐式交集、数组字面量、CSE 多格公式、动态数组/spill、错误值、类型强制、全部内置函数与计算模式。图表、VBA、格式、透视表、UI 等非公式产品能力明确不在公式语言范围内；它们不是用来缩小公式验收范围的借口。

依据与版本钉死见 [ADR 0009：完整符合性终点](adr/0009-full-conformance-endpoint.md)。旧 ADR 0003/0006/0007 已标记 **Superseded by ADR 0009**（保留历史），ADR 0008 的引用语义仍有效、其旧终点表述由 0009 取代。

## 2. 已承诺完整符合性，并公开当前覆盖与缺口

**终点声明：** 以该版本 Excel 公式语言的完整符合性为终点；自定义子集只是当前覆盖，不是验收终点。未实现的标准语义进入 M10–M14 里程碑，不写成“排除在验收分母之外”。

**当前覆盖（截至 2026-11-21）：**

- 真实桌面 Excel 答案键：**1,603/1,603（100%）**，无失败用例移出分母。
  - 旧批 1,267 条（1,169 基础 + 98 引用批）
  - M9 新增数组/交集/并集/`@`/CSE/spill 批 **238 条**，由 COM 探针在真实 Excel 上逐条生成（生成器、版本指纹与 SHA-256 见 [PROVENANCE](../corpus/cases/PROVENANCE.md)）
  - M9.1 新增 spill 引用（`D4#`）批：25 条探针，**23 条**转答案键（`s12`/`s21` 依赖未注册的 `ROWS`，公开函数缺口，不收录）
  - M12.1 新增 SEQUENCE 批 **75 条**（sq001–sq064 + 复跑 p071–p079/q003/q004），全部转答案键
- 单元测试：**182 项，native 与 wasm-gc 双目标同测全过**；零 IO 内核守卫保持。
- 函数：当前 **62 个**（M12.1 新增 SEQUENCE）；目标版本全部内置函数是 M10 里程碑，不把 62 当终点。
- 语义探针：M9 时点 239 条有效探针中 236 条通过；2 条 `SUM (` 是**有意保留的宽松解析**（按任务要求把 `SUM (A1)` 当函数调用，Excel 返回 `#NAME?`，已在 semantics.md 公开分歧），1 条 p126 是覆盖写入锚点的不稳定探针（不作为权威语义），三条均不计入答案键分母。M9.1 的 25 条 spill 引用探针中 23 条与引擎一致并已进分母；2 条 `ROWS` 探针因函数未注册不一致，属公开函数缺口。M12.1 的 75 条 SEQUENCE 探针全部与引擎一致并已进分母。
- 公开缺口：3D 引用、外部工作簿链接、工作表级名称、其他函数的空实参、R1C1、1904 日期系统、locale、其余动态数组函数（FILTER/SORT/SORTBY/UNIQUE/RANDARRAY）等；逐项列在 [项目申报书](../项目申报书.md) 附录 C 与 [semantics.md](semantics.md)。

**分母纪律：** 失败用例逐条归因、修复后重跑；不把失败用例静默移出分母。探针只用于裁定边界，数组批 238 条、spill 引用批 23 条与 SEQUENCE 批 75 条由探针结果转换为主分母的一部分。

## 3. 含交集、隐式交集、CSE、动态 spill 的报表案例与回写结果

新增端到端示例 [`examples/array-demo`](../examples/array-demo/main.mbt)，`Data` 表 A1:C3 = 1..9，`Report` 表 13 个公式，读 xlsx → MoonCalc 计算 → 回写 → 读回逐格断言：

| 能力 | `Report` 公式 | 计算结果 |
| --- | --- | --- |
| 区域交集 | `=SUM(Data!A1:B2 Data!B2:C3)` | 5（交集 B2） |
| 隐式交集（行） | `=Data!A1:A3`（宿主 A2） | 4 |
| 隐式交集（列） | `=Data!A1:C1`（宿主 C3） | 3 |
| 显式 `@` | `=@Data!A1:C1`（宿主 A3） | 1 |
| 并集聚合 | `=SUM((Data!A1:A2,Data!B1:B2))` | 12 |
| 数组字面量/广播 | `=SUM({1,2}+{10;20})` | 66 |
| 2D 宿主不在区域 | `=Data!A1:C3`（宿主 A7） | `#VALUE!` |
| CSE 多格 | `D4:E5 =Data!A1:B2*2` | `[[2,4],[8,10]]` |
| 动态 spill | `G4 =Data!A1:B2+10` | `G4:H5 = [[11,12],[14,15]]` |
| spill 引用聚合 | `E1 =SUM(G4#)` | 52 |
| SEQUENCE 动态锚点 | `J4 =SEQUENCE(3)` | `J4:J6 = [1;2;3]` |
| SEQUENCE spill 引用聚合 | `E2 =SUM(J4#)` | 6 |

回写结果（`_build/array-demo/output.xlsx` 读回断言，**45/45 项通过**）：

- CSE 锚点写为 OOXML `t="array"`、`ref="D4:E5"`，锚点缓存值 `2`；读回断言校验 `formula_type=Array` 与 `range_ref=D4:E5`；followers 按数值类型回写（`4/8/10` 是数值格，不是共享字符串）。
- 动态 spill 锚点写普通公式与缓存值 `11`，spill 格 `H4/G5/H5` 写 `12/14/15`（数值格）；`E1=SUM(G4#)=52`。
- 第二个动态锚点 `J4=SEQUENCE(3)` 写普通公式与缓存值 `1`，spill 格 `J5/J6` 写 `2/3`（数值格）；`E2=SUM(J4#)=6`。
- 公式格的缓存值仍受 mbtexcel 0.3.2 限制写为文本（`t="str"`），已在 demo 文档披露；followers 不再是文本型数字。
- **诚实限制：** mbtexcel 0.3.2 可写 CSE 的 `t="array"`/`ref`，但无动态 spill 元数据；因此动态 spill follower 以字面缓存值回写，读回逐格断言，不声称写入 Excel 动态数组元数据。该限制已写入 [docs/demo.md](demo.md)。
